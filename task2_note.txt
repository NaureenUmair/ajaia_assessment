Task 2 note

This script reads the five supplied exception records, normalizes terminal names (including T3 -> Terminal 3), uppercases carrier codes, and converts the supported timestamp formats to a consistent ISO 8601 representation. It produces a clean count by event type and flags data that should not be guessed. CPX-88216 cannot be fully cleaned because its carrier_code is missing; the script leaves that field blank and explicitly reports it rather than inventing a carrier. I checked that it actually worked by running the script and validating the five records, the expected event-type counts (2 missed_pickup, 2 doc_mismatch, 1 carrier_substitution), T3/Swft normalization, the alternate date format, and preservation of the missing carrier. It uses only Python's standard library, so no external packages are required.
